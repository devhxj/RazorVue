RazorVue takes over the FilePond, VueDraggable, and WangEditor packages.

- `ECMAScript.FilePond` includes the upload component and imperative FilePond API.
- `ECMAScript.VueDraggable` includes the drag-sort component and `UseDraggable` API.
- `ECMAScript.WangEditor` includes the editor and toolbar.

The three packages keep their NuGet IDs, C# namespaces, and upstream npm versions. Use version 2.1.0-preview.8 of the RazorVue packages with Jazor and ECMAScript.Vue at 2.1.0-preview.6.

Package verification builds an independent Razor project that imports all three components and produces a Vite bundle.
