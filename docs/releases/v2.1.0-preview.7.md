RazorVue now maintains and publishes five component binding packages.

- ECMAScript.Vuetify
- ECMAScript.TDesign
- ECMAScript.ElementPlus
- ECMAScript.VueDataUi
- ECMAScript.Lucide

The package IDs, C# namespaces, and upstream runtime versions stay the same. Use the component packages with shared SDK and Vue bindings at 2.1.0-preview.6. Jazor.Vue and Jazor.Admin ship as 2.1.0-preview.7.

The release verifies the binding inventories, NuGet contents, the packaged dashboard, and SPA and SSR browser consumers.
