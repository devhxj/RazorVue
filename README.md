# RazorVue

RazorVue compiles .NET Razor components to Vue render-function modules. It binds the final C# generated by the official Razor Source Generator and delegates C# lowering to Jazor. Existing RazorVue applications can keep their .razor files, component contracts and ModuleCatalog output.

This repository maintains the Razor SDK integration, the Vue runtime bridges, and the Jazor.Admin component library.

## Compatibility

| Jazor.Vue | Jazor SDK and ECMAScript.Vue | NuGet availability |
| --- | --- | --- |
| 2.1.0-preview.5 | Jazor 2.1.0-preview.5 | Published as part of [Jazor preview 5](https://github.com/devhxj/Jazor/releases/tag/v2.1.0-preview.5). |
| 2.1.0-preview.6 | Jazor and ECMAScript.Vue 2.1.0-preview.6 | [First standalone preview](https://github.com/devhxj/RazorVue/releases/tag/v2.1.0-preview.6). |

A Razor authoring project references both Jazor and Jazor.Vue directly. Upgrade them together using the table. The shared Vue bindings now come from the transitive ECMAScript.Vue dependency. Vue ecosystem packages should use the SDK version in the same row.

```xml
<ItemGroup>
  <PackageReference Include="Jazor" Version="2.1.0-preview.6" />
  <PackageReference Include="Jazor.Vue" Version="2.1.0-preview.6" PrivateAssets="all" />
</ItemGroup>
```

## Build and release

Use the .NET SDK selected by global.json. This repository builds against the Jazor version in Directory.Build.props and consumes its NuGet assets. Once that SDK is available on NuGet, run the following from a clean checkout:

```sh
dotnet build RazorVue.slnx
dotnet run --file scripts/csharp/verify-razorvue-coverage.cs
dotnet run --file scripts/csharp/pack-release.cs
dotnet run --file samples/RazorVue.Authoring/verify-smoke.cs -- --configuration Release --package-output artifacts/packages
dotnet run --file scripts/csharp/verify-windows-ssr-release.cs -- --package-source artifacts/packages --path-base /todo
```

The two browser checks use Chrome on Windows. A v-prefixed Git tag sets the Jazor.Vue and Jazor.Admin release version. The publish workflow runs the checks before NuGet Trusted Publishing. The production environment supplies the NUGET_USER secret. NuGet.org must authorize the devhxj/RazorVue repository, the nuget-publish-ref.yml workflow and the production environment for both package IDs.
